# 3D-Zonen

Besondere 3D-Orte (z. B. ein rekonstruiertes Schloss oder ein Gebäude-Zwilling) als Zonen-Paket nach dem
Zonen-Vertrag des Explorers (`docs/zone-contract.md`, Format `sle-zone-v1`, ADR 0015/0016/0048).

Noch leer. Zonen werden in einer späteren Ausbaustufe aus den Ort-Repositories veröffentlicht; bis dahin liefert
der Explorer bestehende Zonen aus seinem eigenen Daten-Repository aus. Bitte vor einer neuen Zone ein Issue
aufmachen: jede Zone braucht eine Lizenzprüfung und eine Datenschutzprüfung (keine Personen, keine Innenräume ohne
Zustimmung der Eigentümer).

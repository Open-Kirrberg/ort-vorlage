# Inhalte

Beiträge der Ortspaten und der Menschen vor Ort. Drei Arten, je ein Ordner:

| Ordner | Was | Lizenz (Feld `lizenz`) |
|---|---|---|
| [`orte/`](orte/README.md) | besondere Orte als Punkte (`*.geojson`) | `CC0-1.0`, aus OpenStreetMap abgeleitet `ODbL-1.0` |
| [`geschichten/`](geschichten/README.md) | Geschichten (`*.md` mit Kopf) | `CC-BY-4.0` oder `CC-BY-SA-4.0` |
| [`bilder/`](bilder/README.md) | eigene Fotos + Bildangaben `<foto>.yml` | `CC-BY-4.0` oder `CC-BY-SA-4.0` |

Alles hier wird nach der Prüfung unverändert auf der Datenseite des Orts veröffentlicht (`inhalte/…`). Der Explorer
zeigt die Inhalte in einer späteren Ausbaustufe an (Plan „Orte skalieren“, S5).
